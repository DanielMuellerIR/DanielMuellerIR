# Hi, I'm Daniel

I build desktop apps for macOS and Linux, iPhone apps, and command-line tools.
Most of my projects work offline. I prefer native interfaces and keep
dependencies small where practical.

My website: [dm0.de](https://dm0.de)

## Productivity

- **[Doppeldecker](https://github.com/DanielMuellerIR/Doppeldecker)** is a dual-pane file manager for macOS and Linux. It copies and moves files, previews synchronization and connects to remote servers. First public preview.
- **[fastra](https://github.com/DanielMuellerIR/fastra)** is a native macOS text editor with replacement previews, Git tools, 4D support and local Markdown editing. A Rust/GTK Linux app is in development and does not yet offer every Mac feature.
- **[favenio](https://github.com/DanielMuellerIR/favenio)** searches files without building an index, including document text and nested archives. It has desktop apps for macOS and Linux and a command-line interface; macOS also has Finder quick search.
- **[stille_post](https://github.com/DanielMuellerIR/stille_post)** turns speech into text locally with Whisper on macOS and Linux. It includes a hotkey, dictation profiles, searchable history, optional text cleanup and result review. Physical-device acceptance on Linux is still pending.
- **[tag_explosion](https://github.com/DanielMuellerIR/tag_explosion)** edits metadata in audio, images, video and e-books, individually or in batches. Desktop apps for macOS and Linux and the command-line tool also inspect electronic invoices without changing them.
- **[md-clip](https://github.com/DanielMuellerIR/md-clip)** converts formatted clipboard text to Markdown. The command-line tool runs on macOS and Linux; macOS also has a Dock app.
- **[jpegdrop](https://github.com/DanielMuellerIR/jpegdrop)** creates JPEG, PNG, AVIF or WebP copies without metadata. Drop images or folders onto its macOS Dock icon and choose a preset, size and output location.

## Audio and music

- **[savage_modplayer](https://github.com/DanielMuellerIR/savage_modplayer)** plays MOD, S3M, XM and IT music with a replay engine written in Swift. There are desktop apps for macOS and Linux, an iPhone app, a Linux command-line player and an HTML5 MOD player. The desktop apps include note rain and exports.
- **[vicious-sidplayer](https://github.com/DanielMuellerIR/vicious-sidplayer)** plays Commodore 64 SID music. The macOS, Linux and iPhone apps have library management, listening queues, and piano and register views. A Linux command-line player and an HTML5 player are also available.
- **[mucke_baby](https://github.com/DanielMuellerIR/mucke_baby)** is a native internet radio app for macOS and Linux. Its seven visual themes react to the audio, and it can record streams and export individual songs.
- **[baby_mucke](https://github.com/DanielMuellerIR/baby_mucke)** is the iPhone sibling of Mucke, Baby! It plays radio in the background, supports lock-screen controls and keeps a track history with Apple Music and Spotify lookup.
- **[hoerbuchkloeppler](https://github.com/DanielMuellerIR/hoerbuchkloeppler)** combines audio files into `.m4b` audiobooks with chapters, cover art and tags. It has a macOS app and a command-line interface.

## Games and graphics

- **[steinregen](https://github.com/DanielMuellerIR/steinregen)** is a falling-block puzzle for macOS and iPhone with six game modes and a black-metal aesthetic. It includes 13 instrumental metal tracks for background music.
- **[exploids](https://github.com/DanielMuellerIR/exploids)** is an Asteroids-style vector shooter for macOS and iOS, with three modes on Mac and two on iOS, nine power-ups and two bosses. On Mac, replays can be exported as GIFs without opening the app.
- **[FraktalLab](https://github.com/DanielMuellerIR/FraktalLab)** runs in the browser. It combines WebGL fractals, demoscene effects, voxel terrain and MOD/SID audio in a grid of panels.
- **[Scientia](https://github.com/DanielMuellerIR/ScientiaPotentia)** is a browser quiz with over 50,000 questions across eight subject areas. It includes interactive visualizations and spaced repetition. Learning progress stays in the browser; no account is required.

## Command-line and developer tools

- **[gitmaster_flash](https://github.com/DanielMuellerIR/gitmaster_flash)** shows the Git repositories below a directory in a terminal interface for macOS and Linux. Inspect changes, branches, worktrees and stashes; apply, pop or delete stashes after preview and confirmation. Its Python core uses only the standard library.
- **[poormans_text](https://github.com/DanielMuellerIR/poormans_text)** converts documents, spreadsheets, presentations, PDFs, images, e-books, email and notebooks to Markdown. It has a macOS app, CLI, profiles and local text recognition. A Linux development preview includes a CLI and optional GTK interface.
- **[ncpin](https://github.com/DanielMuellerIR/ncpin)** sets Nextcloud virtual files to stay local or remain online-only on macOS. It provides a command-line tool, Finder droplets and Quick Actions, including support for Nextcloud Desktop 34 and later.
- **[firefox-tabs-save-and-restore](https://github.com/DanielMuellerIR/firefox-tabs-save-and-restore)** provides `fftabs` for saving, restoring and managing Firefox tabs on macOS. It has a command-line interface and a native app, without additional dependencies.
- **[opencode-minimax](https://github.com/DanielMuellerIR/opencode-minimax)** documents how to configure MiniMax and other Anthropic-compatible models in OpenCode, including the pitfalls of custom providers.

## Linux apps and tools

These projects also run on Linux. The list distinguishes desktop apps from
command-line tools; a Linux version does not imply the macOS interface is available.

- **[Doppeldecker](https://github.com/DanielMuellerIR/Doppeldecker)** has a desktop app and command-line interface, with DEB and AppImage packages for x86_64.
- **[mucke_baby](https://github.com/DanielMuellerIR/mucke_baby)** has a native Qt 6 desktop app for x86-64, with seven themes, listening history, optional recording, M4A song export and MPRIS media controls. A TAR.GZ installer is available; Qt and libVLC 3 come from system packages.
- **[tag_explosion](https://github.com/DanielMuellerIR/tag_explosion)** has a Rust/Tauri desktop app and CLI sharing the Swift file-processing core. Its Linux guide covers installation and updates.
- **[md-clip](https://github.com/DanielMuellerIR/md-clip)** converts clipboard content to Markdown from the command line, with X11 and Wayland support.
- **[savage_modplayer](https://github.com/DanielMuellerIR/savage_modplayer)** has a Qt 6 desktop app with tracker, note rain, collections and exports, plus a separate CLI. Signed updates are integrated from 1.6.58.
- **[vicious-sidplayer](https://github.com/DanielMuellerIR/vicious-sidplayer)** has a Qt desktop app and CLI player with ALSA, MPRIS and WAV export. The app also offers listening queues, piano and register views, and signed updates.
- **[gitmaster_flash](https://github.com/DanielMuellerIR/gitmaster_flash)** runs with Python, Git and curses. Its Linux installer supports Bash, Fish and Zsh; app shortcuts use local executable launchers.
- **[claude-video](https://github.com/DanielMuellerIR/claude-video)** supports frame extraction and transcription on Linux. Video-frame text recognition remains macOS-only.

- **[favenio](https://github.com/DanielMuellerIR/favenio)** has Rust/GTK search and quick-search windows with signed packages; desktop integration has been tested on X11 and Wayland.
- **[stille_post](https://github.com/DanielMuellerIR/stille_post)** has a dictation app with a signed update channel. Tests used artificial audio sources; physical-device acceptance and extended daily use are still pending.

Fastra and Poor Man’s Text also have Linux development builds with remaining feature or acceptance limits; their READMEs describe the scope.

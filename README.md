# Hi, I'm Daniel 👋

I build native macOS and iOS apps and small command-line tools. Most projects
follow the same principles: native UI, offline-capable, scriptable from the
command line, and as few dependencies as possible.

🌐 Website: [dm0.de](https://dm0.de)

## 🖥️ macOS apps

- 📝 **[fastra](https://github.com/DanielMuellerIR/fastra)** — Native macOS text editor with unmatched find & replace: *-wildcards, regex mode, diff preview
- 🔍 **[favenio](https://github.com/DanielMuellerIR/favenio)** — Index-free file search for macOS that also looks inside archives (zip, jar, docx, epub, tar, …) — CLI, native GUI and Finder toolbar quick search
- 🎙️ **[stille_post](https://github.com/DanielMuellerIR/stille_post)** — Local dictation for macOS: Whisper speech-to-text plus honest LLM cleanup that never rewrites — fully offline capable, headless CLI included
- 🏷️ **[tag_explosion](https://github.com/DanielMuellerIR/tag_explosion)** — View and edit media metadata: audio tags, EXIF/IPTC/XMP, video tags, e-book metadata — app and CLI
- 📋 **[md-clip](https://github.com/DanielMuellerIR/md-clip)** — Convert macOS clipboard contents to clean Markdown — CLI, Dock app, and global hotkey

## 🎵 Audio & music

- 🎼 **[savage_modplayer](https://github.com/DanielMuellerIR/savage_modplayer)** — Tracker player for MOD, S3M, XM and IT with an independent Swift replay engine and live scopes (macOS + iPhone; WAV export on macOS)
- 🎹 **[vicious-sidplayer](https://github.com/DanielMuellerIR/vicious-sidplayer)** — Commodore 64 SID chiptune player — single-file HTML5 version and native macOS app with real-time oscilloscope
- 📻 **[mucke_baby](https://github.com/DanielMuellerIR/mucke_baby)** — Native macOS internet-radio player with themed, audio-reactive visualizers (SwiftUI + VLCKit)
- 📱 **[baby_mucke](https://github.com/DanielMuellerIR/baby_mucke)** — Native iPhone internet-radio player — the iPhone sibling of Mucke, Baby! (SwiftUI + AVPlayer)
- 📚 **[hoerbuchkloeppler](https://github.com/DanielMuellerIR/hoerbuchkloeppler)** — Turn loose audio files into a properly chaptered .m4b audiobook — SwiftUI app + CLI

## 🕹️ Games & graphics

- 🧱 **[steinregen](https://github.com/DanielMuellerIR/steinregen)** — Native falling-block puzzle game with six deterministic modes and a raw black-metal aesthetic (macOS + iOS)
- 🚀 **[exploids](https://github.com/DanielMuellerIR/exploids)** — Asteroids-style vector arcade shooter — procedural vector graphics, real-time synthesized audio, two bosses, deterministic replays (Swift 6 / SpriteKit)

## 🧰 Command-line & developer tools

- 🗂️ **[gitmaster_flash](https://github.com/DanielMuellerIR/gitmaster_flash)** — TUI overview of every Git repo below a directory: see what is dirty, unpushed or stashed, and clean it up right there. One Python file, standard library only
- 📄 **[poormans_text](https://github.com/DanielMuellerIR/poormans_text)** — Convert word-processing documents and spreadsheets to Markdown on macOS
- 📌 **[ncpin](https://github.com/DanielMuellerIR/ncpin)** — Set the Nextcloud virtual-files pin state (hydrate/dehydrate) from the macOS command line
- 🦊 **[firefox-tabs-save-and-restore](https://github.com/DanielMuellerIR/firefox-tabs-save-and-restore)** — fftabs: save, restore (lazily) and manage Firefox tabs on macOS — CLI + native GUI, no dependencies
- 🤖 **[opencode-minimax](https://github.com/DanielMuellerIR/opencode-minimax)** — Run MiniMax (or any Anthropic-compatible model) as an agentic coder via OpenCode — solves the custom-provider setup traps
